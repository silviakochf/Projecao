# Projecao
Sistema para projeção de alunos utilizando como base os dados exportados do sistema EducarWeb

FUNCIONALIDADES PRINCIPAIS
Modulo de Progressão. Este móddulo é utilizado para realizar a progressão dos alunos automaticamente integrado com uma IA para auxiliar no remanejamento dos alunos para escolas.
Importação: realiza o parseamento do arquivo pdf (lista de vagas) exportados do EducarWeb.
